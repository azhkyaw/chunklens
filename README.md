# ChunkLens

The local-first inspector & retrieval debugger for ChromaDB. 🚧 Early / pre-release.

## Quickstart (dev)

1. Start a Chroma server: `chroma run --path ./.chroma`
2. Backend: `cd backend && pip install -e ".[dev]" && chunklens`  (opens http://127.0.0.1:8765)
3. Frontend dev server (hot reload): `cd frontend && npm install && npm run dev`
